# Incogra Beta

Marketing site, Chrome extension tour, and a working local studio for Incogra — save, capture, redact, and share from any page.

```
npm install
npm run dev
```

- `/` landing
- `/extension` interactive blur tools
- `/app` local gallery (folders, lightbox, private passcode `0000`)
- `/get-started` beta + Chrome load-unpacked steps
- `/privacy`

Join-beta submissions are stored in the browser (`localStorage`) until a backend is wired.
