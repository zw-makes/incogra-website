Incogra — Visual Reference & Privacy Redaction Platform

Application Purpose

Incogra is a visual moodboard and reference library for designers, creators, and researchers to save web inspirations and redact sensitive personal information (such as emails, addresses, and account numbers) before sharing. Google Sign-In is used solely for secure authentication.

Strict Prohibition of AI NCII (Non-Consensual Intimate Imagery)

In strict compliance with Google APIs Terms of Service, Incogra strictly prohibits the creation, generation, upload, storage, processing, or distribution of AI-generated Non-Consensual Intimate Imagery (AI NCII), sexually explicit material, or unauthorized deepfakes. Incogra tools and connected Google APIs may never be used to facilitate intimate or non-consensual content.

Google Account & API Usage

Incogra integrates Google Sign-In solely for identity verification and account authentication via Supabase Auth (requesting basic openid, email, and profile). Incogra does not access, read, or process personal user data from any other Google service, and strictly complies with the Google API Services User Data Policy.
